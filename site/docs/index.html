Pensieve documentation

This page tells you what Pensieve is, what its parts do, and where to start.

Pensieve keeps the context of your work in one place on your Mac. It indexes your files, git repos, AI agent sessions, tickets and messages. You search it from a panel. Your coding agents search it over MCP. Each person's context is different, so Pensieve builds it from your own work and keeps it on your Mac.

Pensieve is free and open source under the MIT license. It is for developers and their AI agents.

The main parts

Threads

Pensieve makes one thread for each goal of your work. A thread joins the agent sessions, the branch, the PRs, the tickets and the messages of that goal. It says the problem, the goal, the state and what is next. It also gives the steps left to close it, and the command that resumes the last agent session. Each thread has one of five states: To do, Open, Loose ends, Complete or Forgotten. You can share a thread as one HTML file. Read about threads.

MCP server

Pensieve is an MCP server. Your coding agent asks it one question and gets the few files and lines that match. Each hit shows the path, the line, the enclosing definition and the line that matched. Each agent connection works in a scope. By default, the scope is the repo that the agent started in. Connect your agent, or read the MCP tools reference.

Search

Search finds items by meaning and by exact words. It blends a vector search with a full-text search. Then it gives more weight to exact text and to names that a file defines. A search takes about 0.1 to 0.2 seconds. On a Mac, press Control+Shift to open the search panel.

Who knows what

Pensieve reads git blame for each indexed repo. Ask about a subject, not a file, and it names the people who wrote the most related code. Agents get the same data from the people tool.

Knowledge gaps

A knowledge gap is an area of a repo that people who are no longer active wrote most of. For each area, Pensieve shows who wrote it, which active person knows it best, and its bus factor. The bus factor is the number of active people who hold 10% or more of the lines. By default, a person with no commit in 180 days is not active.

Connections

Connections collect your tickets, threads and pages from MCP servers such as Jira, Slack and Linear. Pensieve calls only read-only tools. Each connection is off until you switch it on. Read about connections.

What Pensieve indexes

You choose each source at setup. You can change your choice in Settings → Sources.

  • AI agent sessions: Claude Code, Codex and Qwen Code transcripts.
  • Files and folders: documents in ~/Documents, ~/Desktop, ~/Downloads and the folders that you add.
  • Git repositories: committed, staged, modified and untracked files, and linked worktrees.
  • Apps: Obsidian vaults and, with your permission, Apple Notes.
  • Connections: items from MCP servers. Each one is off by default.

Pensieve never indexes files that look like secrets, such as .env files, keys and credentials.

Models

Pensieve runs one model: the search model. It turns text into vectors, and it always runs on your computer. The default for a new index is EmbeddingGemma 2.

Pensieve has no text model of its own. Your agent writes thread notes, summaries and insights with its own model, through Pensieve's MCP tools. Search, agent context, ownership and knowledge gaps do not need the agent.
