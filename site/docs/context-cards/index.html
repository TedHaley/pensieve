Context cards

This page tells you how Pensieve makes a context card for each task, how it sets the state, and how you share a card.

What a card holds

Every card has the same core: the problem, the goal, the state and what is next. It also holds the question that waits on you. The rest of the card is its resources, the evidence behind the core:

  • The folders where the work is: the repo, the branch, the worktree, uncommitted files, and how far the branch is ahead or behind.
  • The PRs, with their state, CI checks and review.
  • The tickets, with their status and assignee.
  • The agent sessions, and the command that resumes the last one.
  • When you ask, coworkers' recent commits in the same folders, and related tickets and threads.

A short AI note says what is done and what is left. The note needs a generation model. Without one, the card has its evidence but no note.

How Pensieve joins a task

Pensieve joins sessions, branches, commits and connection items into one task by these links:

  • A ticket key such as ABC-123 in a branch name, a commit subject, a session or a ticket.
  • The git branch that a session ran on. This applies only to feature branches. A default branch holds many tasks.
  • For work with no ticket: sessions in the same repo, at most 3 days apart, that edited the same files.
  • Session titles that mostly match, within 3 days.

Pensieve leaves out sessions in temporary folders and under ~/Library. Apps and scripts start those.

The five states

Pensieve sets each state from the task's evidence. Material work is edits, commits, a branch or a PR.

StateMeaningSet automatically when
ConsciousYou work on it now.A session runs now. Or the task has material work and activity in the last 3 days, and it is not done.
SubconsciousIt is not done and it is quiet. Go back to it.It has material work that is not done, with no activity in the last 3 days.
LatentA ticket that you did not start.A ticket that is not done, or with an unknown status, and no edits, commits, branch or PR.
EtchedDone.A PR is merged, nothing happened after the merge, and no PR is open. Or its own PR is merged and no PR is open. Or its PRs are merged or closed, or its ticket is done, and nothing is uncommitted.
ForgottenNot finished, and it will probably stay that way.Material work that is not done, quiet for 21 days, with no open PR and no uncommitted work. Or a conversation with no ticket and no edits, after its session ended.

You can set a state on the card. An agent can set one with set_task_state. A state set by hand stays until the task has new activity. Then the automatic state applies again. Pensieve keeps each change by hand, so a task has a history of its states.

Threads

Each card belongs to a thread: one goal, followed over time. Pensieve saves a thread's card when it changes, for example when a PR opens, a commit lands or the next step changes. The thread chip on a card opens its saved cards. “New session from card” starts an agent that reads the card first. Agents get the same data from thread_history.

Share a card as HTML

The Share button on a card opens a preview. Pensieve reads the local resources whole and writes a summary of each one. Then you can do these steps:

  1. Write what you need from the reader.
  2. Edit the core and the summaries.
  3. Clear the resources that do not belong.
  4. Save the card as one HTML page in Downloads.

The page has no outside files. A person opens it in a browser. The page also holds the card as JSON in a <script type="application/json" id="context-card"> element, so the reader's agent reads the same file. Agents share a card with the share_card MCP tool. Pensieve does not send the file. You or your agent attach it to a message.

What a shared card keeps

Each resource has a reach: who can open it. The reach sets what a shared card does with the resource.

ReachResourcesIn a shared card
localSession transcripts, agent memory files, uncommitted or unpushed changes, files outside git, foldersA summary, written from the whole document when you share. No path.
gitThe branch on the remote, files at a pushed commit, PRsA link (a permalink at the commit)
mcpTickets, messages and pages from your connectionsA link and its service, with a summary. A message goes as a link only, without its text.
restrictedClaude artifactsA link marked “may need access”, with a summary
publicPublic web pagesA link
privateDirect messages, group messages, private channelsNothing: no link, no text, no summary

A shared card has no local paths, session ids, resume command or secrets. Pensieve replaces text that looks like a key or a token with [secret]. It also removes sentences about your own computer from the core.

Cards from the command line

pensieve card <task id> -o card.html    # the card as one HTML page
pensieve card <task id> --json          # the card as JSON
pensieve card <task id> --share -o card.html   # the card to send

A card follows the context-card/1 JSON schema. The tasks MCP tool gives the task ids.

Cards for your agents

Agents get the same cards over MCP. tasks lists them by state. task gives one card. When an agent finishes a task, it marks it etched with set_task_state. With the Claude Code prompt hook, a prompt such as “where did I leave off on ABC-12” gets the card before the agent starts.
