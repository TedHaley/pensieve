Privacy and data

This page tells you where Pensieve keeps your data, and each time that Pensieve or your agent uses the network.

What stays on your computer

  • Indexing and search run on your computer. The search model always runs locally.
  • Pensieve keeps everything in ~/.pensieve: the index, the settings, the collected connection items and the feedback reports. To start again, remove that folder.
  • The backend listens on 127.0.0.1 only, port 8765 by default. Other computers cannot connect to it.
  • The app and the backend have no analytics and no account.
  • Pensieve never indexes files that look like secrets: password-manager kits, keys, .env files and credentials. The exclude_files setting lists the patterns.
  • Pensieve keeps its git data in ~/.pensieve/git. It does not write to your repos.

Your agent

Pensieve is a tool that your agent calls. If you use a cloud agent, such as Claude Code or Codex, what the agent reads from Pensieve goes to its provider, the same as a file that it reads with grep. Pensieve sends nothing to the agent until the agent calls a tool. The Claude Code prompt hook is the exception: it adds context to each prompt in an indexed repo.

Shared cards and feedback

  • Shared cards: Pensieve saves a shared card as a file in Downloads. It does not send it. Before you save, you see the card and can edit it. A shared card has no local paths, session ids, resume command, secrets or private messages (see What a shared card keeps).
  • Feedback: reports from you and from agents stay in ~/.pensieve/feedback.jsonl. Settings → Feedback lists them. Send to GitHub opens an issue with the text filled in, and you read it before you post it.

Private messages

Items from direct messages, group messages and private channels are context for your own cards and agents only. A shared card leaves them out whole. See Connections.
