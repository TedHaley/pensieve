Connect your agent

Pensieve for Claude Code

This page tells you how to connect Claude Code to Pensieve over MCP, and what changes on your computer.

Connect Claude Code

  1. Install Pensieve (see Install).
  2. Run one of these commands: 
    pensieve integrate recommended   # every agent on this computer
pensieve integrate claude-mcp claude pensieve-search   # only Claude Code
  3. Restart Claude Code. It loads its MCP servers when it starts.
  4. Ask Claude Code a question about your code, for example “where do we retry failed webhooks?”.

What Pensieve adds

Add-onIdFile
MCP serverclaude-mcp~/.claude.json (through claude mcp add --scope user)
Instructions blockclaude~/.claude/CLAUDE.md
Skillspensieve-searcha link to ~/.agents/skills in ~/.claude/skills

The instructions block goes in ~/.claude/CLAUDE.md, between <!-- pensieve:start --> markers.

Or install the Claude Code plugin

The plugin gives Claude Code the MCP server, the four skills, the instructions block and the three recommended hooks. It does not change your settings files. Install Pensieve first, because the plugin starts ~/.local/bin/pensieve. Then type these commands in Claude Code:

/plugin marketplace add TedHaley/pensieve
/plugin install pensieve@pensieve
  • Use the plugin or pensieve integrate for Claude Code, not both. When the plugin is installed, pensieve integrate skips the Claude Code MCP server, instructions block, hooks and skill link.
  • The plugin's tools have names that start with mcp__plugin_pensieve_pensieve__.
  • If the backend uses another port, set PENSIEVE_PORT in the environment that starts Claude Code.

Hooks for Claude Code

pensieve integrate recommended adds three hooks to ~/.claude/settings.json:

HookEventWhat it does
claude-hookPostToolUseAfter each Edit or Write, it sends the changed path to Pensieve. The next search finds the new code. It adds about 50 ms to each edit.
claude-repo-checkSessionStartIn a repo that Pensieve does not index, Claude asks you once whether to index it. Pensieve keeps your answer. In a repo that Pensieve indexes, it adds one line: the number of loose ends and the thread closest to done. Claude then offers to close it at a natural pause.
claude-prompt-searchUserPromptSubmitPensieve adds what the prompt needs: a thread, your list of threads, who knows the code, past sessions, or the 5 best code matches. It adds about 300 ms and 400 to 1,500 tokens.

Slash commands, prompts of 1 or 2 words, and repos that Pensieve does not index get nothing from the prompt hook.

Connect by hand

claude mcp add --scope user pensieve -- pensieve mcp      # every project, scope "auto"
claude mcp add pensieve -- pensieve mcp --scope payments     # this folder only, a named scope
claude mcp add --transport http pensieve "http://127.0.0.1:8765/mcp?scope=payments"

Without --scope user, claude mcp add connects only the folder that you run it in. Claude Code shows the tools as mcp__pensieve__search, mcp__pensieve__read and more.

Remove

pensieve integrate claude-mcp claude --remove

Pensieve removes only the entries that it added.
