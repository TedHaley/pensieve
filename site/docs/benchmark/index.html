Benchmark

This page tells you how we measured Pensieve against grep, what the results are, and what we did not measure.

−47%tool calls per lookup: 1.81 against 3.42
−23%cost per lookup: $0.039 against $0.051
−29%time per lookup: 6.8 s against 9.5 s
90%tasks solved, the same as with grep (129 / 144)

These four numbers are from the latest batch (2026-10-13), with clean Claude Code settings. Pensieve solves as many tasks as grep, with about half the tool calls. An earlier batch, with Pensieve 0.5.6, solved 91% against 85% with grep. The two later clean batches did not repeat this gain. Both results are below.

Method

The script is bench/agent_search.py. It does these steps:

  1. It makes tasks from indexed code. Each task describes one piece of code. The answer is the file that holds it.
  2. It writes each task in one of these styles: a plain description, a name that the code defines, an error string from the code, or a mix of a name and words.
  3. It splits the tasks into a dev set, which we used to tune Pensieve, and a test set, which we did not use to tune.
  4. It runs Claude Sonnet headless through Claude Code (claude -p) on each test task, once in each setup.
  5. It records whether the answer names the right file, the tool calls, the tokens, the time, and the cost that Claude Code reports.

Cost depends on the state of Claude's prompt cache. The same tokens can cost 4 times more with a cold cache. Thus we compare cost only between setups in one batch. Calls, tokens and time can be compared between batches.

Results: later batches with clean settings

The first batch loaded the Claude Code settings of the computer that ran it. Later, the script loads only the settings of the repo (--setting-sources project,local). These are the last of those batches, run on 2026-10-13 with the same 72 tasks:

SetupSolvedTool callsCost per lookupTime (mean)
grep129 / 1443.42$0.0519.5 s
guided129 / 1441.81$0.0396.8 s
only130 / 1441.70$0.0386.5 s
  • Accuracy is level with grep. The 6-point gain of the first batch did not come back with clean settings. This task set suits grep: most descriptions use words that are in the code.
  • Cost and time are lower. Guided was 23 to 25% cheaper and 25 to 29% faster than grep in the two clean batches.
  • 6 tasks fail in every setup. Their description fits a near-copy of the answer as well as the answer.

In the top 8 results, which is what the search tool shows, Pensieve has the right file for 91.6% of queries. Grep has it for 53.1%. On the held-out queries only, @1 is 66.7% against 35.2%. A search took 73 ms at the median, on an Apple M4 Max. Grep is level with Pensieve on exact strings. STRATEGIES.md lists every ranking method that we tried, with its numbers.

What we did not measure

  • Other models and agents. Every agent run used Claude Sonnet in Claude Code. We did not measure Codex, Cursor, Gemini CLI, Qwen Code, Windsurf, Claude Desktop or VS Code.
  • Other repos. The tasks come from four repos on one developer's computer. We do not publish their names.
  • Full coding tasks. Each task asks the agent to find one file. We did not measure whether Pensieve helps an agent fix a bug or ship a feature.
  • Generated tasks. A model wrote the tasks from the code. Real questions from real sessions are noisier. We have only about 18 of them, too few to report.
  • Independent runs. Nobody outside the project has run the benchmark yet.
  • Linux and Intel. All runs were on Apple Silicon.
  • The prompt hook. The optional claude-prompt-search hook cut tool calls by 33 to 46% in three batches. Its accuracy was level with guided, and its cost was the same. The results above do not use it.

Data and scripts

The scripts are in bench/. The run files hold paths and code from the four repos, so they are not public. To get your own numbers, run the benchmark on your repos:

uv run python bench/agent_search.py gen --repo ~/code/my-app -n 40 --tasks tasks-v2.jsonl
uv run python bench/exact_tasks.py      # adds name, error-string and mixed tasks
uv run python bench/agent_search.py run --repo ~/code/my-app --tasks tasks-v2.jsonl --arms grep,guided

Use a copy of an index (PENSIEVE_DATA), not ~/.pensieve. Run a server on the copy for the agent runs.
